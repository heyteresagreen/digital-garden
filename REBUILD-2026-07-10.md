# teresawatts.com rebuild — session summary, 10 July 2026

## What changed

### Site (digital-garden repo — full rebuild)
- Replaced the Obsidian Digital Garden plugin with a custom Eleventy v3 build:
  8 owned Nunjucks templates, no plugin constraints, no client-side JS
  (the old site shipped Alpine.js + filetree markup on every page).
- New URL structure with sections: /writing/, /notes/, /art/, /sketching/,
  /sketchbooks/, /books/, /letters/, /projects/, plus /posts/ (mixed feed,
  two-column mosaic), /tags/ + per-tag archives, RSS at /feed.xml, 404.
- 64 × 301 redirects in netlify.toml map every old URL; all targets verified.
- Design carried over from tw-style.scss, plus: active nav states, section
  labels, prev/next links, pagination, per-section list styles (writing
  thumbnails, letters bullets, art/sketchbook mosaics, book grid),
  footer hidden pending restyle.
- Notes became their own garden-style section, separate from Writing.
- "Books in progress" is a snippet note — editable from Obsidian, rendered
  into /books/ at build time.
- Automatic image optimisation: every image converted to webp (≤1400px),
  content-hashed, lazy-loaded. Wide images bleed past the text column only
  when genuinely wider than it.

### Vault (teresawatts v2 — now the single source of truth)
- 141 published notes clean-migrated to new frontmatter (publish, section,
  date, description, imageUrl, slug); dg-* keys removed; originals backed up
  (vault-frontmatter-backup.json in the repo).
- Dataview dashboards rewritten for the new fields and new paths.
- Reorganised (923 moves, log at _reorg-log.md):
  website/ (all publishable, by section) · inbox/ (134 captures, ex-raw/,
  tagged status: inbox + source/url) · notes/ (private evergreen; topics/;
  sources/ for course + literature notes) · life/ (recipes, exercise,
  finances, ex-private/) · dashboards at root.
- Dashboard.md is now a workbench: inbox oldest-first, website drafts,
  recently edited notes, "growing" notes ready to consider publishing.
- Duplicates found and resolved (7 in repo, 1 in vault); 3 broken thumbnail
  paths fixed; 2 missing dates recovered from git history; AI/ai tag merged.
- To empty when convenient: vault _to-delete/ folder and the repo's
  src/site/_old-notes-DELETE-ME/ + .write-test + two root stubs.

## Estimated performance impact (vs old live site)

- Image-heavy pages ~85–90% lighter: originals averaged ~570KB–3MB each;
  optimised webp median is 108KB (sample: 3.1MB scan → 425KB, visually
  identical). The art index alone drops roughly 20MB+ → ~3MB.
- JavaScript: ~zero now (was Alpine.js + plugin scripts, ~50–100KB + parse
  time on every page). Faster first paint, nothing to block rendering.
- All images lazy-load with async decoding — initial viewport loads only
  what's visible.
- Content-hashed image URLs are cacheable indefinitely; 24h cache headers
  already covered /img/* and /styles/*.
- Builds: first ~4–5 min (one-off image conversion, cached thereafter —
  locally in dist/, on Netlify via netlify-plugin-cache), then seconds.

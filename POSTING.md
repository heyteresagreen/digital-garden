# How to publish a post

## The frontmatter every post needs

```yaml
---
title: Watercolour magpies
publish: true
section: art          # writing | art | sketching | sketchbooks | books | letters | projects
date: 2026-07-15
tags: [art, watercolour]
description: Optional one-line summary shown on index cards
---
```

That's it. Notes:

- No `publish: true` → the note is ignored by the build entirely.
- No `section` → the post appears only in the Posts feed, at `/posts/slug/`.
- Cards on index pages automatically use the **first image in the post body**
  as their thumbnail — no extra field needed. To override it, add
  `image: /img/user/assets/something.jpg`.
- The URL slug comes from the filename. To override: `slug: my-custom-slug`.
- Wiki links (`[[Note name]]`) and image embeds (`![[image.jpeg]]`) still work.

## Example: an art post, start to finish

1. Write the note with the frontmatter above (`section: art`).
2. Put the artwork photo in the note body as a normal image.
3. Publish it (see below). It appears at `/art/watercolour-magpies/`,
   on the Art index (with thumbnail), in the Posts feed, and in the RSS feed.

## Publishing — two ways

**Until Enveloppe is set up:** add the `.md` file to `src/site/notes/art/`
in this repo (any folder works — the `section` field decides where it appears,
folders are just for your own organisation). Add images to
`src/site/img/user/assets/`. Commit and push via VSCode Source Control;
Netlify rebuilds in ~2 min.

**Once Enveloppe is set up** (see ENVELOPPE-SETUP.md): write the note in
Obsidian with the same frontmatter, then command palette →
"Enveloppe: Upload all notes" (works on iOS too). Enveloppe pushes to GitHub
and Netlify rebuilds.

## Special pages

- **About** and **Now** live at `src/site/notes/About.md` and `Now.md`. They have
  `permalink:` and `standalone: true` in their frontmatter — edit the content
  freely (from Obsidian once Enveloppe is set up), keep those fields.
- **Index pages** (Posts, Writing, Art, Books, etc.) are generated by templates —
  the old Obsidian index notes with dataview tables are no longer published.
  Keep them in your vault if they're useful there, but don't give them
  `publish: true`.
